Q: What is MCP?
A: Open standard for connecting AI applications to external tools and data through one protocol — often described as USB-C for AI.

Q: MCP host vs client vs server?
A: Host = the AI application (e.g. Claude Desktop); client = the connection handler inside it; server = the program exposing capabilities.

Q: The three MCP primitives?
A: Tools (actions the model can invoke), resources (data to read), prompts (reusable templates).
