Q: What is Data Cloud in one sentence?
A: Salesforce's lakehouse-based customer data platform that ingests, harmonizes, unifies, and activates data from any source.

Q: What is a CDP?
A: A system that unifies customer data from many sources into persistent profiles usable by other tools; Data Cloud is Salesforce's CDP and more.

Q: What is a lakehouse?
A: Architecture combining a data lake's cheap open storage with a warehouse's query performance and governance.

Q: The Data Cloud flow, in order?
A: Ingest → model → unify → insight → activate.
