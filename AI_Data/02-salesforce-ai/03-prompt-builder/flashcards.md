Q: What is Prompt Builder?
A: Declarative tool for creating reusable prompt templates that merge CRM record data and grounding sources before calling an LLM.

Q: What is a prompt template?
A: A reusable, versioned prompt definition with merge fields, resolved with live data at runtime.

Q: What is dynamic grounding?
A: Injecting live CRM or Data Cloud data into a prompt at runtime so the model answers from your data instead of general knowledge.
