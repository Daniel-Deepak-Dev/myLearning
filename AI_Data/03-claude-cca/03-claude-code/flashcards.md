Q: What is CLAUDE.md?
A: A project memory file Claude Code reads automatically — conventions, architecture notes, commands — shaping every session's behavior.

Q: What is headless mode?
A: Running Claude Code non-interactively with the -p flag, typically in CI pipelines, often with JSON output for automation.

Q: What is the Claude Agent SDK?
A: Anthropic's framework for building production agents with the same loop, tools, and context management that power Claude Code.
