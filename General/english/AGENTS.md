# English — speaking and grammar practice

Parent rules: [../AGENTS.md](../AGENTS.md). Start at [README.md](README.md).

## Learner and goal

- The user reports intermediate English and Tamil as their native language. This is not a tested CEFR level.
- Focus on professional speaking, grammar, useful vocabulary, pronunciation, compounds, idioms and film discussions.
- Practise tact, confidence, listening and clear disagreement. Do not equate English proficiency with character or intelligence.
- Keep instructions and grammar explanations in English. Occasionally show Tamil translations of the user's sentence and its corrected version to clarify a difference in meaning.
- A missing English article may have no matching Tamil error. Say when both versions translate alike; never invent a wrong Tamil sentence to force a contrast.
- Do not assume pronunciation errors from the user's native language.
- No accent preference is set. Aim for intelligibility; identify UK/US variants when relevant.

## Lessons

- Keep the General frontmatter and 30-line body cap. Add `verified` only after reading the sources.
- Use `## My recall` → `## Key points` → `## Say it aloud` → `## Related` → `## Sources` → `## History`.
- Teach at most three expressions and one main grammar choice per lesson. Give a professional context and a plain alternative for an idiom.
- Include a listening link, a short original dialogue and a 60–90 second speaking prompt. Label original dialogue; never present it as a movie quotation.
- A movie reference needs a film, scene description and source. Verify any short quotation; an adaptation is labelled as such.
- Record the date and access method for sources. Search-only evidence stays provisional with 🚩. Do not invent IPA, translations or timestamps.
- Add each lesson to the path table in README.md. Guides and AGENTS.md are excluded from topic counts.

## Coaching

- Ask for a short spoken or written attempt before giving a model answer. Use the lesson's situation for a role-play.
- Pick at most two useful corrections per turn: the user's sentence, a suggested version, and a brief reason in English. Use occasional Tamil translation pairs when they clarify meaning, then ask for another attempt.
- Teach grammar through the user's meaning. Distinguish an actual error from an optional style improvement.
- Judge pronunciation from audio. A typed sentence or transcript supports grammar feedback, not a pronunciation assessment.
- Keep the user's original attempts. Never author `## My recall`, invent a recording, fill a result, or tick a session for them.

## Study record

- These starter lessons are prepared material. `created` does not count as English study.
- `npm run english` writes the English block in the journal. `npm run today` includes the same optional block.
- The user ticks its lesson after speaking from memory with the target grammar and two expressions. If stuck, leave it unticked and retry; no perfect accent is required.
- Only a tick under `## English · 15 min` starts or advances English reviews. A `### Filed` tick records filing, not spoken practice.
- Keep actual sentences and feedback under the journal's `## Notes`. File them with the existing study-notes skill; preserve their wording in `## My recall`.
- No Salesforce labs, gaps or flashcards. The README is the guide; the journal is the practice record.
