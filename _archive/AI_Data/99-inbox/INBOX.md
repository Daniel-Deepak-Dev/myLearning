# Inbox — Capture First, File Later

Anything you learn or stumble on that isn't in the roadmap goes here as one bullet, immediately. Triage during your weekly journal session:

- Fits an existing track → create the next-numbered topic folder there (copy the four files from [_templates/](../_templates/)), add it to that track's `INDEX.md`, delete the bullet.
- New term only → add it to [GLOSSARY.md](../GLOSSARY.md).
- Not worth a folder → leave it here with a link, or delete it.

Format: `- [ ] <thing> — <why it seemed worth keeping> — <source link>`
