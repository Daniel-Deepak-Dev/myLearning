Q: What is a search index in Data Cloud?
A: Unstructured content (PDFs, transcripts, knowledge) that Data Cloud has chunked and embedded so it's semantically searchable.

Q: What is Data Cloud's vector database?
A: The built-in store of embeddings for unstructured content, powering semantic search and grounded AI answers.

Q: What is chunking and why does it matter?
A: Splitting documents into pieces before embedding — chunk size and overlap strongly affect retrieval quality.

Q: What is semantic search?
A: Retrieval by meaning using embedding similarity rather than keyword matching.
